# FluidTwin V2

개방형 냉각수 루프의 **운전상황 가정 해석** 플랫폼. 하나의 수리 모델을 2D PFD 화면과 맵 화면에서 탭으로 전환해 보며, 실제 물리 수준(V&V 벤치마크 통과)의 정상·과도 해석을 브라우저에서 수행한다.

작업 계획·설계·진행 상황: [`docs/PLAN-V2.md`](docs/PLAN-V2.md)

## 범위 (확정 결정 요약)

| 항목 | 내용 |
|---|---|
| 대상 계통 | 냉각탑 수조 → 펌프 A/B → 열교환기 → 제어밸브/바이패스 → 라이저 → 살수 헤더 → 수조 |
| 유체 | 물 단상, 온도 고정 (열교환기는 ΔP 요소) |
| 화면 | 전부 2D (Canvas 2D). PFD / 맵 탭 전환 |
| 편집 | 격자 스냅 + PFD 심볼 외형. 배관 길이 = 셀 수 × 셀 크기, 세로축 = 실제 고도 |
| 수조 | 수위 변화 포함. 보충수·블로다운 없음 |
| 시나리오 | 정상운전 운전점 + 펌프 A/B 전환, 제어밸브 조작 + 바이패스 |
| 제외 | 온도/열수지, 수주분리(DVCM), 충수·배수, 다성분, 3D, 계측 실데이터 연동 |

V1(3D/격자 샌드박스) 문서는 [`docs/archive/v1/`](docs/archive/v1/)에 보관.

## 실행

```bash
npm install
npm run dev        # 개발 서버
npm test           # 단위·V&V 테스트
npm run build      # 타입체크 + 프로덕션 번들
```
