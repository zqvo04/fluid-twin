# FluidTwin V2 — V&V (검증·확인) 기록

[PLAN-V2.md §5](PLAN-V2.md)의 10개 항목에 대한 기준값, 출처, 허용오차, 실측 결과, 테스트 위치. 모든 항목은 `npm test`에 포함되어 매 변경마다 다시 확인된다.

## 알려진 모델 한계

| 항목 | 내용 |
|---|---|
| 운전 중 펌프 (MOC) | 강성 수두 링크 근사(V1)로 정상해 대비 유량 약 5 % 편차. 기동·트립 중인 펌프는 펌프 곡선 그대로라 해당 없음 |
| 수조 수위 | 명시적 오일러 적분(Δt 0.5 s). 고갈은 "다음 스텝에 바닥 아래로 내려갈 때" 흡입 상실로 판정 → 질량은 정확히 보존되나 펌프가 바닥 도달 직전(최대 한 스텝 분량의 물이 남은 채)에 송출을 멈춤 |
| 험프 곡선 기동 | 모터 구동 펌프만, 최고 수두 위 얇은 대역(1 % + 0.05 m)에서 유량 선형 감소로 연속화 |
| 제외 범위 | 온도/열수지, 수주분리(DVCM, 망 MOC는 증기압 하한 클램프만), 충수·배수, 다성분 — PLAN-V2 §0 |
